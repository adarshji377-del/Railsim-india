# Railsim-india
**🔍 Interactive Train Search &amp; Quota Filter:**   - Filter trains by **Origin Station**, **Destination Station**, **Travel Date**, and **Quota** (*General (GN)*, *Tatkal (TQ)*, *Senior Citizen (SS)*).   - Dynamically recalculates seat availability and ticket fares based on the selected quota.  - **🟢🟡🔴 Color-Coded Class Availability Cards (1A,2A)
